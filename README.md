# Barttolo World Expansion (BWE)

Proyecto experimental para **Minecraft Java 1.20.1 / Forge 47.4.10 / Java 17** destinado a ampliar RingWorld mediante construcciones en chunks ya generados.

## Estado

**En desarrollo. No instalar en el servidor principal.** El prototipo local v0.6.0 incluye construcción de ocho tipos originales, análisis de terreno y deshacer. Aún necesita una compilación Forge verificada, pruebas en un mundo de copia y revisión del sistema de restauración.

## Seguridad

- Ejecutar pruebas solamente en una **copia** del mundo, nunca en la instancia activa.
- Proteger las misiones, las bases y el camino principal antes de construir.
- Las estructuras de **CTOV y Explorify NO están redistribuidas** aquí; obtener permisos antes de incluir activos de terceros.
- Las instrucciones para compilar y ejecutar las pruebas están incluidas en el ZIP de fuentes v0.6.0 preparado durante el desarrollo.

## Siguiente paso

Incorporar el árbol de fuentes, activar GitHub Actions y corregir errores de compilación. La compilación por sí sola no demuestra que el mod sea seguro para un mundo existente.
